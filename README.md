# TaskFlow AI

Dashboard moderna per team, task e inbox AI.

## Requisiti

- Node.js 18+
- npm

## Installazione

```bash
npm install
```

## Avvio locale

```bash
npm run dev
```

Apri la pagina su:

- http://localhost:3000

## Build di produzione

```bash
npm run build
```

## Note

Questa è una demo UI pronta per essere collegata a un backend reale o all'agente Microsoft 365.
